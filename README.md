# RiffLab

Versión sin IA de RiffLab preparada para GitHub Pages.

## Publicar en GitHub Pages

1. Crea o usa un repositorio llamado `RiffLab`.
2. Sube **todo el contenido de esta carpeta** a la rama `main` (no solo `App.jsx`).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment → Source**, selecciona **GitHub Actions**.
5. Haz un push a `main` y espera a que termine el workflow **Deploy RiffLab to GitHub Pages**.
6. La aplicación quedará en `https://TU-USUARIO.github.io/RiffLab/`.

La configuración de Vite ya usa `base: '/RiffLab/'`, por lo que funciona cuando el repositorio se llama exactamente `RiffLab`.
